# Dostaffkin

Веб-приложение для управления доставками и отслеживания статуса заказов.

## О проекте
Dostaffkin — сервис доставки посылок между странами и внутри стран. Платформа предоставляет возможность быстро оформить заказ доставки, расчитать стоимость и отследить статус в режиме реального времени. 

## Функционал

### Главная страница (Home)
Информационная страница с описанием сервиса и быстрыми ссылками на:
- Оформление новой доставки
- Отслеживание посылки

### Создание заказа (Order)
Полнофункциональная форма оформления доставки:
- Выбор точки отправления и прибытия (с подсказками Яндекс.Карт)
- Визуализация маршрута на интерактивной карте
- Автоматическое определение текущего расположения (геолокация)
- Выбор размера посылки (xs, s, m, l, xl) и скорости доставки (regular, fast)
- Динамический расчет стоимости
- Ввод контактных данных (имя, телефон, комментарий)
- Создание и отправка заявки на сервер

### Отслеживание (Track)
Мониторинг статуса доставки:
- Ввод номера отправления
- Получение и отображение информации о статусе доставки
- Уведомления об ошибках и успехе операции

## Технологический стек

- **Frontend**: Angular 21.1.1, TypeScript 5.9.3
- **Состояние и реактивность**: RxJS 7.8.2
- **Уведомления**: ngx-toastr 20.0.4
- **Маршрутизация**: Angular Router
- **HTTP запросы**: Angular HttpClient
- **Тестирование**: Vitest 4.0.18
- **Пакетный менеджер**: npm 10.9.2

## API Endpoints

| Метод | Эндпоинт | Описание |
|-------|----------|---------|
| POST | `https://testologia.ru/delivery/create` | Создать новую доставку |
| GET | `https://testologia.ru/delivery/info` | Получить информацию о доставке |

## Установка и запуск

### Установка зависимостей
```bash
npm install
```

### Разработка
```bash
npm start
```
Приложение доступно по адресу `http://localhost:4200`

### Продакшн-сборка
```bash
npm run build
```

### Наблюдение за изменениями
```bash
npm run watch
```

### Тесты
```bash
npm test
```

## Структура проекта

```
src/
├── app/
│   ├── pages/
│   │   ├── home/       — главная страница
│   │   ├── order/      — создание заказа
│   │   └── track/      — отслеживание доставки
│   ├── services/
│   │   └── delivery-api.ts — клиент API доставки
│   ├── app.routes.ts   — маршруты приложения
```

## Маршруты

- `/` — главная страница
- `/order` — страница создания заказа
- `/track` — страница отслеживания
- `**` — редирект на главную
